# Student Grade Calculator

A simple student grade management program written in C.

The program stores student names and grades and provides several basic operations on them.

## Features

- Add students
- List students
- Calculate the average grade
- Find the highest grade
- Find the lowest grade
- Search for a student by name
- Delete a student by name

The program currently supports up to 10 students and grades between 0 and 100.

## What I practiced

- Structures
- Arrays
- Functions
- Pointers
- Strings and `strcmp`
- Basic input validation
